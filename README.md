# homebrew-tools

Tap personal de Homebrew para mis propias herramientas de línea de comandos.

## Uso

```sh
brew tap nikodc/tools
brew install claude-env-switch
```

## Fórmulas disponibles

- **claude-env-switch**: switch de perfiles de configuración de Claude Code.
  Código fuente y setup inicial en
  [nikodc/claude-env-switch](https://github.com/nikodc/claude-env-switch).
