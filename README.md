# homebrew-tools

Tap personal de Homebrew para mis propias herramientas de línea de comandos.

## Uso

```sh
brew tap nikodc/tools
brew trust nikodc/tools
```

Al ser un tap de terceros, Homebrew puede pedir confirmación para confiar en él.
